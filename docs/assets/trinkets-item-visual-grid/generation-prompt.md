# Prompt da prancha conceitual

```text
Use case: stylized-concept
Asset type: Minecraft Bedrock item sprite-sheet concept board for Dorios' Trinkets
Primary request: Create one large, perfectly aligned sprite sheet showing 84
distinct possible item visuals from the RPG-Core / Dorios' Trinkets content plan.
Input images: Image 1 is a STYLE REFERENCE ONLY. Match its compact
Minecraft-like item icon language: chunky silhouettes, selective highlights,
dark outlines, vivid but controlled colors, readable tiny objects. Do not copy
any individual icon and do not recreate the Windows Explorer UI.
Scene/backdrop: a flat very dark neutral charcoal background with a strict square
grid and subtle 1-pixel-looking dividers; no environment, no interface chrome.
Style/medium: authentic hand-authored pixel art, Minecraft Bedrock inventory item
texture aesthetic, crisp hard pixel edges, no anti-aliasing, no blur, no painterly
shading, no vectors, no 3D render.
Composition/framing: EXACTLY 12 columns by 7 rows, therefore EXACTLY 84 cells and
84 icons. Every cell contains exactly one centered, unique item icon. Equal cell
dimensions, equal padding, no empty cells, no merged cells, no icons crossing
dividers. Treat every icon as designed on an EXACT 16×16 logical pixel canvas,
shown enlarged with nearest-neighbor scaling so the individual square pixels
remain visible and crisp. Wide rectangular contact sheet, orthographic/front or
slight isometric inventory-icon view as appropriate.
Lighting/mood: readable game-inventory contrast with tiny specular pixel clusters;
mysterious fantasy-adventure mood.
Color palette: Minecraft-compatible earthy leather, iron, copper, gold, amethyst,
emerald, ocean teal, nether ember red, void purple, sacred white-gold, with
category variety.

Row-major icon subject order, one icon for each numbered entry:
ROW 1 — Adventurer's Belt; Ironbound Girdle; Miner's Tool Belt; Tideforged
Girdle; Bloodbound Sash; Toolwright Belt; Soulcatcher Belt; Hunter's Bandolier;
Builder's Harness; Magma Cinch; Marksman's Monocle; Plague Doctor Mask.
ROW 2 — Ember Respirator; Copper Prospecting Lens; Echo Visor; Mirror Mask; Veil
of Silence; Ender Visor; Witch's Crooked Hat; Paladin Circlet; Tideforged Crown;
Miner's Helmet; Beekeeper's Hat; Crown of Last Light.
ROW 3 — Stormcaller Hood; Featherstep Anklets; Tidewalker Fins; Sabaton Weights;
Sandstrider Boots; Rootwalker Sandals; Frostwalker Soles; Shadowstep Greaves;
Slimebound Boots; Stone Guardian Doll; Hollow Doll; Lucky Ragdoll.
ROW 4 — Straw Effigy; Marionette of Spite; Creeper Doll; Leech Doll; Guardian
Effigy; Void Covenant; Endless Eye; Phoenix Ash Sigil; Chronoshard; Worldroot
Knot; Stormbound Idol; Glutton's Seal.
ROW 5 — Lapis Focus; Geode Amulet; Prismatic Aegis; Moonstone Amulet; Sunstone
Amulet; Echoheart Amulet; Gravekeeper Amulet; Tempest Heart Amulet; Wardstone;
Hunter's Fang; Ocean Coin; Quarry Sigil.
ROW 6 — Totem of Momentum; Wayfinder Compass; Stormglass Talisman; Harvester's
Token; Traveler's Cloak Pin; Alchemist's Cloak Pin; Iron Locket; Emerald Chain;
Wayfarer's Knot; Miner's Token; Duelist Wraps; Builder's Glove.
ROW 7 — Empty Belt; Reinforced Belt; Blank Mask; Enchanted Visor Frame; Porcelain
Doll Core; Bound Doll Frame; Archaic Binding; Attunement Shard; Trinket Fragment;
Stat Inscription; Cleansing Thread; Resonance Core.

Distinctive design requirements: belts must read as waist equipment, face items
as masks/lenses, hats as headwear, feet items as footwear/anklets, dolls as small
effigies, archaic charms as uncanny relics, amulets as pendant objects, talismans
as handheld tokens, and materials as crafting components. Maintain strong
silhouette diversity and avoid repeating the same ring, orb, or necklace
silhouette.
Text: none.
Constraints: exactly 84 icons; exactly one icon per cell; all item art is based on
a strict 16×16 logical pixel grid; nearest-neighbor pixel scaling only;
transparent-looking or dark empty padding inside each cell; consistent scale;
clean sprite-sheet alignment; no labels, numbers, letters, logos, watermark, UI,
cursor, filenames, borders around individual objects, shadows outside cells,
gradients, smooth edges, anti-aliasing, blur, photorealism, duplicated icons,
human figures, or scenery.
Avoid: fake text, Windows Explorer interface, high-resolution painted objects,
rounded vector icon style, excessive glow that destroys silhouettes.
```
