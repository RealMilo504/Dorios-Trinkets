# Prompt da folha de ícones

Modo: ferramenta integrada de geração de imagens.

Use case: stylized-concept

Asset type: Minecraft Bedrock trinket inventory sprite sheet

Primary request: create exactly twelve distinct fantasy trinket icons in a
strict 4-column by 3-row grid, one centered object per equal square cell,
ordered left-to-right and top-to-bottom:

1. silverfish-scale ring;
2. breeze-core loop ring;
3. ominous trial-key ring;
4. phantom-membrane mantle;
5. armadillo-scute shield brooch;
6. lost allay bell charm;
7. desert-temple scarab charm;
8. compact snow-golem doll;
9. shipwrecked drowned doll;
10. wind bracer gauntlet;
11. cracked bastion gold medallion;
12. jungle-temple relic.

Style/medium: crisp Minecraft-inspired pixel art game item icons, chunky
deliberate pixels, strong silhouettes, restricted palette, dark outline and
subtle one-pixel highlights, visually compatible with 16x16 inventory items.

Composition/framing: exact evenly spaced 4x3 grid; every object isolated and
fully contained inside its cell with generous transparent padding; no cell
borders; no overlaps.

Constraints: genuinely transparent background; exactly twelve objects; no
text, numbers, labels, letters, frames, logos, watermark, shadows outside each
icon, background scenery, or extra objects. Each cell must remain legible after
independent nearest-neighbor downscaling to 16x16.
